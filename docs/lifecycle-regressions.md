# 异常流程与回归测试

## 运行

```sh
./gradlew build
./gradlew -I tools/review-regressions/init.gradle runReviewRegressions --console=plain --no-configuration-cache
```

GitHub Actions 分别执行普通构建和完整 GameTest 回归，任一步骤失败都会使工作流失败。测试源集仍与发布产物分离。无界面 GameTest 验证服务端逻辑；客户端画面仍需在游戏中检查。

## 已明确的生命周期规则

- 首领的一次抓取绑定到实际生成成功的抓取弹 UUID。旧弹体不能完成或取消下一次抓取。弹体永久移除时结束相应动作；弹体暂时不可查时保留 20 tick 的恢复宽限，不强制加载区块；首领重新加载时取消未完成的瞬态抓取。
- 引导之光、无尽索求及其护卫不能通过正常跨维度传送离开战斗所在维度。普通区块卸载不会删除护卫的站立记录。
- 上捞在服务端实际传送完成后重新定位碰撞采样，包括短距离及同 tick 内多次传送。普通连续移动仍执行扫掠检测，跨维度则结束上捞。
- 心智处决记录目标、发令者和原绑定身份。正常伤害及死亡规则仍然有效；失败后保留仍有效的控制关系，不在后续 tick 自动反复施伤。玩家再次明确发出处决命令才重试。旧 UUID-only 任务在改写实体归属前迁移。
- 心智信标的主动扫描、处决和模式修改分别共享单 tick 执行预算；重复选择当前模式不重置战斗目标或导航。控制范围、被动扫描间隔保持不变。
- 战斗成员与控制成员通过各自的数据管理类修改，集合读取不可绕过持久化标记。合金锅的固定配方和特殊材料索引延迟初始化并缓存；对外提供材料副本。

本轮没有修改 FE 换算／输出策略，也没有修改研究材料优先级或费用匹配规则。
